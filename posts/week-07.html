F1 Telemetry Engine (Part 1): Scrapping the Prototype for Something that Actually Works

Remember the 2023 Monza GP simulation I showed you guys in the mid-week drop? The one that looked like a crude Matplotlib plot but put my poor laptop into a 5-hour coma? 😅

Well, once the machine finally woke up and I had some time to think, a harsh reality hit me. I wasn't actually building the legit F1 hub I was dreaming of. I had just duct-taped together some code that worked for exactly one specific race🫠🫠🫠

The Monza Prototype & The Hardcoded Wall

My initial proof-of-concept was grabbing FastF1 data, pushing it through a Python backend, and streaming it to an HTML/JS dashboard. It worked, but it had a fatal flaw—it was hardcoded only for the 2023 Monza Qualifying session😅😅

If I wanted to compare Verstappen and Norris at Monza, I should be able to do that. Want to switch to Abu Dhabi 2025? That should be a dataset change—not a code surgery. But with the way I'd built the prototype, even that would've meant rewriting half the application. It was a "rewrite-everything-and-cry" kinda situation😭😭.

That brought up the ultimate question: How do I build this so that adding a new race later requires zero code changes???

Creating A New Repo

My portfolio site(this website) lives on GitHub Pages, which is amazing for static HTML and CSS, but it absolutely cannot run a Python backend or process heavy data. Instead of cramming everything into one chaotic codebase, I created an entirely new repo (f1-telemetry-api) deployed on Render to handle the heavy data and FastF1 API stuff. Sounds smart ryt?? Ik im goated😎🗿

This keeps the main portfolio clean while the backend evolves independently on its own cloud server. Hopefully, no more frying my local motherboard💀💀💀

A New Mindset

The biggest mental shift was killing the idea of building an "Abu Dhabi 2025 Dashboard" and instead building a dynamic system where Abu Dhabi is simply a dataset.

I redesigned the system around a clean, logical data hierarchy:

📂 Season 
 └── 📂 Grand Prix 
     └── 📂 Session 
         └── 📂 Driver 
             └── 📄 Telemetry

Adding a new race in 2026 will literally just mean dropping a new folder into the dataset directory. No backend rewrites required!!! Pure plug-and-play baby😏😏😏(to any recruiters reading this, I will not accept anything less than 50k a month, it’s a fair deal to hire someone as legendary as I’m🗿😎😁)
